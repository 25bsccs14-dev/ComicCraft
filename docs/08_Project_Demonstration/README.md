## Demo Video Checklist
Record a screen-share video with your voice explaining the project. Follow the SmartBridge instructions and ensure the final Google Drive link is set to “Anyone with the link can view.”

## Suggested Demo Script
### 1. Introduction
“Hello, my name is [Name], from [Department and College]. My project is ComicCraft – AI Comic Story Creator.”

### 2. Purpose
“The purpose of ComicCraft is to help users turn a simple idea into a short comic-style story and an AI-generated illustration.”

### 3. Technologies
“The project uses Python and FastAPI for the backend, HTML/CSS and Jinja2 for the webpage, Gemini for story generation, and a hosted Hugging Face inference service for illustration generation.”

### 4. Live Execution
- Show the ComicCraft home page.
- Enter a sample idea.
- Click Generate.
- Explain that the application sends the idea to the AI services.
- Show the generated story and illustration, if both services are available.

### 5. Uses and Benefits
“ComicCraft can support creative brainstorming, storytelling practice, and comic concept development. It demonstrates how a web application can integrate AI services.”

### 6. Conclusion
“This concludes my demonstration of ComicCraft – AI Comic Story Creator. Thank you.”
